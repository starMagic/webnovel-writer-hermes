# 市场扫描技能

> 目标：让从没写过网文的小白，通过"看市场 → 选方向 → 对标分析 → 缝合起步"，而不是被追问"你的题材是什么？"

## 触发条件

- "市场扫描"、"分析平台"、"最近什么题材火"
- "我想写网文但不知道写什么"
- "番茄和七猫哪个适合新手"
- init 流程中的小白路径自动触发

## 执行原则

1. 先展示平台差异，让用户选平台；再展示该平台的热门方向，让用户选方向
2. 每个方向给一个"小白友好度"评分，降低选择焦虑
3. 联网搜索优先获取最新数据；预置知识作为 fallback
4. 输出格式 = 选项卡片，不是长篇报告

## 数据刷新

启动时先尝试联网获取最新数据：

```bash
# 番茄热榜
curl -s --proxy http://127.0.0.1:31181 "https://www.baidu.com/s?wd=番茄小说+2025+热门品类+排行榜" -H "User-Agent: Mozilla/5.0" 2>/dev/null | python3 -c "import sys,re;print('\n'.join(re.findall(r'[\u4e00-\u9fff]{10,100}',sys.stdin.read())[:20]))" 2>/dev/null || echo "联网获取失败，使用预置数据"
```

## 三大平台速查

### 番茄小说

| 维度 | 详情 |
|------|------|
| 所属 | 字节跳动 |
| 模式 | **免费 + 广告分成** |
| 读者画像 | 18-35岁为主，男频略多，下沉市场渗透深 |
| 读者偏好 | 快节奏、爽点密集、代入感强、不喜欢铺垫 |
| 日更要求 | 4000-6000字，保持稳定 |
| 收入模式 | 广告分成 + 番茄作家激励计划，头部月入10万+ |
| 小白友好度 | ⭐⭐⭐⭐⭐（门槛最低、推荐机制对新人友好） |

**当前热门品类（2025-2026）：**

| 品类 | 热度 | 小白难度 | 核心卖点 | 代表特征 |
|------|:--:|:--:|------|------|
| 都市异能 | 🔥🔥🔥🔥🔥 | ⭐⭐ | 现实代入感 + 超能力爽感 | 隐藏身份、扮猪吃虎、反转打脸 |
| 系统流 | 🔥🔥🔥🔥🔥 | ⭐ | 框架明确、升级清晰 | 系统发布任务→执行→奖励，循环推进 |
| 玄幻修仙 | 🔥🔥🔥🔥 | ⭐⭐⭐ | 世界观宏大、成长线长 | 废柴逆袭、境界突破、法宝机缘 |
| 规则怪谈 | 🔥🔥🔥🔥 | ⭐⭐⭐ | 新奇设定、强悬念 | 怪谈规则→破解→存活，每轮一个规则 |
| 游戏体育 | 🔥🔥🔥 | ⭐⭐ | 电竞/体育竞技爽感 | 天赋+系统辅助，比赛制胜 |
| 脑洞悬疑 | 🔥🔥🔥 | ⭐⭐⭐⭐ | 反转多、完读率高 | 每章一个反转，读者欲罢不能 |
| 年代/种田 | 🔥🔥🔥 | ⭐⭐ | 生活气息、温馨治愈 | 日常生活+系统辅助，轻松向 |

**番茄爆款通用公式：**
- 前3章必须有3个以上的小反转/爽点
- 每章结尾留钩子（不是"悬念"，是让读者想知道"然后呢"）
- 主角要有明确目标（报仇/变强/赚钱），每章推进一步
- 对话占比 40%+，描写占比 20%-，节奏要快
- 章均 2000-2500 字，太长了番茄读者会流失

**番茄新手建议：**
- 首选：**系统流** 或 **都市异能** — 框架清晰、上手快、读者基数大
- 避免：**传统玄幻**（竞争太激烈）、**历史**（知识门槛高）

- 章均 2000-3000 字

**七猫新手建议：**
- 首选：**豪门总裁** 或 **青春甜宠** — 套路成熟、读者稳定

### 起点中文网

| 维度 | 详情 |
|------|------|
| 所属 | 阅文集团 |
| 模式 | **付费订阅 + 月票/打赏** |
| 读者画像 | 18-35岁、男频占70%+、一二线城市、阅读深度最高 |
| 读者偏好 | 逻辑自洽、世界观完整、人物有深度、接受铺垫 |
| 日更要求 | 4000-6000字（精品文可3000字） |
| 收入模式 | 订阅分成（千字X分钱） + 月票 + 打赏 + 版权 |
| 小白友好度 | ⭐⭐（竞争激烈、读者挑剔、起量慢） |

**当前热门品类（2025-2026）：**

| 品类 | 热度 | 小白难度 | 核心卖点 | 代表特征 |
|------|:--:|:--:|------|------|
| 玄幻修仙 | 🔥🔥🔥🔥🔥 | ⭐⭐⭐⭐ | 深度世界观+完整力量体系 | 凡人流/苟道流/稳健流是近两年热点 |
| 都市异能 | 🔥🔥🔥🔥 | ⭐⭐⭐ | 现实+超自然 | 克苏鲁元素/规则类能力/文明升级 |
| 科幻无限 | 🔥🔥🔥🔥 | ⭐⭐⭐⭐ | 世界观新奇、想象力 | 诸天流/无限流/末日流，每卷一个世界 |
| 历史架空 | 🔥🔥🔥 | ⭐⭐⭐⭐⭐ | 需要知识储备 | 考据严谨+合理爽感，门槛最高 |
| 游戏竞技 | 🔥🔥🔥 | ⭐⭐ | 电竞/虚拟现实 | 游戏系统+竞技对抗+升级打怪 |

**起点爆款共性：**
- 世界观自洽——读者会逐章考证，设定 bug 会被骂
- 人物有弧光——主角不能是平面工具人
- 付费章节节奏慢一点没关系，免费章节前 20 章必须有套路化的爽点节奏
- 月票榜就是命——更新稳定比爆发更重要

**起点新手建议：**
- **不建议纯小白首选**。先在其他平台练笔 30-50 万字再来起点。
- 除非：你对某个领域（历史/科幻/游戏）有深度积累，能写出别人写不了的东西。

## 小白选平台决策树

```
你想写哪种？
  ├── 爽文、快节奏、男频 → 番茄
  │     ├── 纯小白 → 系统流
  │     ├── 有点想法 → 都市异能
  │     └── 敢挑战 → 规则怪谈
  │
  ├── 言情、甜宠、女频 → 七猫
  │     ├── 纯小白 → 豪门总裁 / 青春甜宠
  │     ├── 有生活阅历 → 年代种田
  │     └── 野心大 → 古言宫斗
  │
  └── 深度世界观、有知识积累、不急 → 起点
        ├── 修仙/玄幻 → 找准一个流派深耕
        └── 科幻/无限 → 需要强设定能力
```
