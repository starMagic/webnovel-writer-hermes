# 对标书分析

> 目标：让小白通过"看别人怎么写的 → 提取可抄的模式 → 缝合出自己的故事"，而不是从零创作。

## 触发条件

- "拆解某某书"、"分析这本书为什么火"
- "番茄都市异能有什么爆款？帮我分析"
- "我想写系统流，帮我找几本对标书拆一下"
- webnovel-market 流程的后续衔接

## 执行原则

1. **输出是选项卡片，不是分析报告**——每张卡片一句话说清"你可以怎么抄"
2. **给模式不给内容**——提取的是钩子结构、节奏模板、人设骨架，不是具体情节
3. **多本书交叉对比**——同一品类的 3-5 本书放在一起比，才看得出规律
4. **小白友好翻译**——不说"叙事距离控制"，说"不要把读者推太远，让读者觉得主角就是自己"

## 两种输入模式

### 模式 A：指定书名

用户提供 2-5 本书名 + 平台：
```
"拆解番茄上的《xxx》《xxx》《xxx》这三本都市异能"
```

### 模式 B：指定品类（推荐）

用户只给平台 + 品类：
```
"番茄都市异能最近有什么火书？帮我分析"
```

此时先联网搜索该品类近期的热书，确定 3-5 本对标书后再分析。

---

## 输出：五类选项卡片

每张卡片格式：

```
📇 卡片类型：[钩子/节奏/人设/爽点/结构]
📖 来源：[书名]（[平台]）
🎯 模式：[一句话概括可复用的模式]
🧩 如何抄：[具体操作方法，1-2 句]
⚠️ 注意：[抄的时候要避开的坑]
```

### 卡片类型说明

| 类型 | 提取什么 | 给小白怎么用 |
|------|---------|------------|
| **钩子卡片** | 前 3 章怎么抓读者 | 你的第一章第一句可以怎么仿写 |
| **节奏卡片** | 爽点出现的频率和分布 | 每多少字来一个爽点，怎么排 |
| **人设卡片** | 主角+反派+女主的特征组合 | 你的人设骨架可以怎么搭 |
| **爽点卡片** | 让读者"爽"的机制 | 打脸/升级/曝光/逆袭的触发方式 |
| **结构卡片** | 章节内部的组织方式 | 每章的结构模板（开头→中间→结尾） |

## 执行流程

### Step 1：确定对标书单

**模式 A（用户指定书名）：**
```bash
# 联网获取该书的基本信息
curl -s --proxy http://127.0.0.1:31181 "https://www.baidu.com/s?wd={书名}+{平台}+简介+评价" -H "User-Agent: Mozilla/5.0" 2>/dev/null | python3 -c "import sys,re;print('\n'.join(re.findall(r'[\u4e00-\u9fff]{20,200}',sys.stdin.read())[:10]))" 2>/dev/null
```

**模式 B（指定品类）：**
联网搜索"番茄 2025 都市异能 推荐 排行"等关键词，获取 3-5 本热书。优先选完本的（模式完整），其次选连载中且字数 > 50 万的。

### Step 2：逐书提取模式

对每本书，提取以下维度（如果只能获取简介和评论，就基于简介+评论提取；如果能获取正文前几章，就基于正文提取）：

1. **钩子**：第一章前 500 字做了什么？怎么抓住读者的？
2. **人设**：主角是什么类型？（废柴逆袭 / 隐藏大佬 / 穿越者 / 重生者 / 天赋异禀）
3. **金手指**：系统/传承/重生/血脉？金手指的规则和代价？
4. **节奏**：前 10 章有多少个爽点？爽点的间隔是几章？
5. **对话比**：对话占比高（快节奏）还是描写占比高（慢节奏）？
6. **升级链**：主角的成长路径（境界/等级/财富/地位）

### Step 3：交叉对比 + 生成卡片

把所有书放在一起对比：

```
┌──────────┬──────────┬──────────┬──────────┐
│   书名   │  钩子    │  人设    │  节奏    │
├──────────┼──────────┼──────────┼──────────┤
│  书A     │ 穿越+危机│ 废柴逆袭 │ 2章/爽点 │
│  书B     │ 重生+复仇│ 隐藏大佬 │ 1章/爽点 │
│  书C     │ 穿越+系统│ 天赋异禀 │ 1章/爽点 │
└──────────┴──────────┴──────────┴──────────┘

共同规律：穿越/重生开头占100% → 这是该品类的标配钩子
差异点：书A和B节奏稍慢但人设深度更强 → 适合想写长线的
      书C节奏快但人设模板化 → 适合追求短期流量的
```

### Step 4：输出"缝合建议"

基于交叉对比，输出 2-3 个缝合方案：

```
🔧 缝合方案 A（保守型）：
  钩子 = 书A的穿越危机模式
  人设 = 书B的隐藏大佬骨架
  节奏 = 书C的1章1爽点节奏
  → 适合：追求稳定表现，不想冒太大风险

🔧 缝合方案 B（差异化）：
  钩子 = 书A的框架 + 把"穿越"换成"重生"
  人设 = 书C的天赋流 + 加入书B的反差性格
  节奏 = 书B的慢节奏 + 前3章用书C的快节奏拉留存
  → 适合：想在同品类里做出一点差异
```

## 输出示例

```
📊 番茄都市异能 · 对标分析

对标书：《我在都市斩妖除魔》《都市之最强战神》
        《我的系统不一般》《都市修仙之王》《重生都市天尊》

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📇 钩子卡片 ×3
─────────────────────

卡片1：穿越/重生 + 立刻危机
  来源：《重生都市天尊》（番茄）
  模式：主角重生回到10年前，第一章就面临前世导致他死亡的危机
  怎么抄：你的主角也在第一章第一页就面临一个具体威胁（被追杀/被开除/被退婚）
  注意：危机要具体，不要"世界末日"这种虚的

卡片2：系统激活 + 新手任务
  来源：《我的系统不一般》（番茄）
  模式：第1章系统激活，立刻发布第一个任务（时限24小时），完成有奖励
  怎么抄：系统激活后不给主角喘息时间，马上进入"执行任务"模式
  注意：第一个任务要简单但有陷阱，让主角聪明地解决

卡片3：隐藏身份被撞破
  来源：《都市之最强战神》（番茄）
  模式：主角低调做人，第一章被人挑衅，被迫暴露一部分实力
  怎么抄：前三章安排3次"被小看→打脸"循环，逐步升级对手
  注意：打脸要有递进，不能第一章就打完最终boss

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📇 人设卡片 ×3
─────────────────────

卡片4：废柴外表 + 隐藏实力
  来源：5本书共同特征
  模式：主角在普通人面前低调，但拥有远超常人的能力/背景
  怎么抄：给主角设置一个"不能公开实力"的约束（系统限制/保护身边人/躲避仇家）
  注意：约束要合理，不能每次都靠"懒得解释"糊弄过去

...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 推荐缝合方案（新手首选）

方案名称：「快节奏系统流都市异能」

钩子 = 卡片2（系统激活+新手任务）
人设 = 卡片4（废柴外表+隐藏实力）
节奏 = 1.5章/爽点，前10章≥6个爽点
金手指 = 签到系统 + 升级可视化

预计效果：番茄普通推荐池，前3天可测出留存率
```

## 充分性闸门

- 至少分析了 3 本书
- 每种卡片类型至少输出了 2 张
- 至少提供了 2 个缝合方案
- 每张卡片有明确的"怎么抄"而不是空泛分析
